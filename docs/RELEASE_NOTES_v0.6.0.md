# AppVolumeControl 0.6.0

发布日期：2026-08-16

## 重点修复

- 默认不再自动接管新应用的声音路径。打开 AppVolumeControl 本身不会为抖音、浏览器等应用创建 Process Tap。
- 没有公开独立音量接口的应用现在显示“原始输出 · 未启用独立增益”，用户点击“启用独立增益”后才会建立系统级输出增益会话。
- 默认输出增益固定为 75%。关闭“记住每个应用的输出增益”时，新的接管会话不会继承上一次的数值。

## 设置

- 面板右上角新增设置入口，可设置默认输出增益、自动接管新应用、是否记住每个应用的输出增益，并可清除已记住的数值。
- 自动接管和应用记忆默认关闭，以避免播放刚开始时发生不必要的声音路径切换。

## 边界

- 抖音和浏览器的控制项是公开 Core Audio Process Tap 提供的“输出增益”，不是应用或网页播放器自己的内部音量。
- 浏览器标签页级音量需要独立的浏览器扩展，0.6.0 不会伪造该能力。
